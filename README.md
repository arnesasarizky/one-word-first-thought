The entry word is "petrichor" — the smell of rain on dry earth — chosen as the first word that came to mind. It is a vivid, surprising word: a single noun that carries a whole scene of storm, soil and relief, which is exactly what a first thought should do.

## Run it

`MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts` writes entry.txt containing exactly the word `petrichor`, with no trailing newline.
